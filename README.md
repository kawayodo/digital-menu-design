# digital-menu

川淀のモバイルメニュー（料理・ドリンク・持ち帰りの全メニュー）。外国人のお客さま向けの6言語メニューで、注文内容を日本語で店員に見せる画面も持つ。ビルド不要の素の HTML / CSS / JavaScript で、GitHub Pages でそのまま配信している。

公開URL: https://kawayodo.github.io/digital-menu/

## ファイル構成

```
index.html     画面の構造と動き（インライン script）
style.css      見た目（下の「デザイン」を参照）
menu-data.js   商品・オプション・翻訳・営業時間などのデータ（xlsx から生成。手で直さない）
images/        商品写真（WebP・横幅 800px 以下・1枚 100KB 以下）
assets/logo.png      ロゴ（布地つき。favicon に使用）
assets/logo-ink.webp ロゴから墨の筆文字と落款だけを抜いた透過画像（入口の暖簾とヘッダーに使用）
```

外部ライブラリ・CDN・サーバー処理は使っていない。`index.html` をブラウザで直接開けば動く。

### データの正と生成スクリプト（このリポジトリの外）

`menu-data.js` は次の xlsx から生成している。どちらも公開しないので、このリポジトリには入れていない。

- `川淀_フルメニュー.xlsx` … 料理・持ち帰り・コース・営業時間（「注意事項」シート）
- `川淀_ドリンクメニュー.xlsx` … ドリンク

生成・検査・画像変換のスクリプトは、xlsx と同じ親フォルダの `tools/` にある（使い方は `tools/README.md`）。

```
川淀/
├── 川淀_フルメニュー.xlsx
├── 川淀_ドリンクメニュー.xlsx
├── images/                元の写真（jpg）
├── tools/                 gen_menu_data.py ほか
└── digital-menu/          ← このリポジトリ
```

## メニューを更新するとき

1. xlsx を直す（日本語の言い回しは xlsx の記述がそのまま画面に出る）
2. `川淀/` フォルダで `tools/README.md` の「生成」と「検査」を実行する
   - 新しい商品を足したときは、翻訳（英・韓・中簡・中繁・エスペラント）を `tools/` 側に足さないと生成がエラーで止まる（推測で埋めないため）
3. `digital-menu/` の変更をコミットして push する（数分で公開に反映）

価格・伝票略号・アレルギー表示は、検査スクリプトが xlsx と1行ずつ突き合わせる。

## 画面

`.screen` を持つ4つの `<div>` を `showScreen(id)` で切り替える。

1. **入口**（`entry-screen`）— 言語と「店内でお召し上がり／お持ち帰り」を選ぶ。年齢確認はしない。選ぶと暖簾が左右に分かれてメニューが現れる（`enterThroughNoren()`。中身は今までどおり `setService()`）
2. **メニュー**（`menu-screen`）— 選んだ側の商品だけを表示。店内は料理のあとにドリンクが並ぶ（ドリンクは店内のみ）。ヘッダーの切り替えで店内／持ち帰りをいつでも変えられ、カートは消えない
   - オプションがある商品は［追加］（コースは［選ぶ］）で画面下からシートが開く。オプションがない商品は行の「－ ＋」で直接カートに入る
3. **注文確認**（`order-screen`）— 選択中の言語で表示。店内と持ち帰りを別の枠に分け、合計（税込）を出す。ドリンクがあるときは「お持ちするタイミング（食事より先に／一緒に）」を選ぶまで次へ進めない
4. **店員表示**（`staff-screen`）— **常に日本語・価格なし**。伝票に書き写せる略号で表示する

## データの持ち方（menu-data.js）

- `PRODUCTS` … 商品。サイズ違い（並串・中串…）は `variants` に持ち、価格と伝票略号は variant ごと。サイズのない商品も variant を1つ持つ
- `OPTION_GROUPS` … オプション。`slipAbbr` が店員画面の略号。初期値を持つのは「ご飯の量（普通）」と「コースのメイン（変更なし）」だけで、それ以外は必ずお客さまに選ばせる
  - `type: "count"` … グラス数・お猪口数（1〜20 の数を選ぶ）
  - `countAs` … 持ち帰りの有料オプション（きも吸い +290円・紙袋 +22円）。店員画面では単独の「持 きも吸い」「持 紙袋」と合算して1行で出す
  - `course-main` … コースのメイン変更。`inheritFrom` で通常メニューの商品のオプションをそのまま引き継ぐ
- `CATEGORIES` … `service`（dinein / takeout）・`kind`（food / drink）・`stop`（どのオーダーストップ時刻を使うか）
- `VESSELS` … ドリンクの容器。瓶は「本数・グラス数」、清酒は「徳利数・お猪口数」を聞き、数量＝本数（徳利数）
- `UI_TEXT` / `STAFF_TEXT` … 画面の文言（6言語）と店員画面の文言（日本語）

## 店員画面の書き方

- 料理：伝票略号を大きく、オプションの略号をその下にスペース区切りで（例：`並セイロ ×1` / `ネ M`）
- コースと定食（肉）：料理ごとに行を分け、行の先頭に料理名を小さく出す（ご飯の「M」と焼き加減の「M」を区別するため）
  ```
  もえぎ ×1
    国産牛  R なし
    セイロ  なし L
  ```
- ドリンク：店内の枠の料理のあとに、提供タイミングと一緒に（例：`久保田` / `徳利：2本 / お猪口：3杯 / 飲み方：熱燗`）
- 持ち帰り：オプションのきも吸い（温・冷ごと）と紙袋は、単独の「持 きも吸い」「持 紙袋」と合算

## カートの保存

- `localStorage` に保存（iPhone の Safari が再読み込みしたときや、QR を読み直して新しいタブで開いたときも消えない）
- キーは `kawayodo_food_cart` / `_lang` / `_service` / `_timing`。同じ `kawayodo.github.io` のドリンク版などとぶつからないよう `kawayodo_food_` で始める
- 最後の操作から **3時間** で捨てる（次の来店時に前回の注文が出ないように）
- 保存するのは variant の ID・選んだオプション・数量だけ。商品名と価格は読み込み時に `menu-data.js` から引き直し、存在しなくなった商品・オプションを含む行は黙って捨てる
- 保存に失敗する環境（プライベートブラウズなど）でも画面は普段どおり動く

## オーダーストップ

お客さまのスマホの時計を使うので、注文不可にはせず、該当カテゴリとシートに警告帯を出すだけにしている（最終判断は店員）。時刻は xlsx「注意事項」シートから読む。

| 対象 | 警告を出さない時間 |
|---|---|
| 店内の料理 | 11:00〜14:30、17:00〜19:00 |
| コース | 11:00〜14:00、17:00〜18:30 |
| ドリンク | 11:00〜14:30、17:00〜19:30 |
| 持ち帰り | 11:00〜19:00 通し（昼休みも提供できるため、昼のラストオーダーは適用しない） |

## アレルギー表示

- xlsx にアレルギー表記がある商品は「アレルギー表示：小麦・卵」のように表示する
- 表記がない商品（一品料理・ドリンクなど）は、空欄にせず必ず「アレルギー情報は店員にお尋ねください。」を表示する（空欄は「アレルゲンなし」と受け取られるため）
- メニューの最下部と注文確認画面に、混入の可能性についての注意書きを出す

## 写真

店内の定食だけに付けている（単品・持ち帰りには流用しない）。steak は牛肉の写真なので、牛の定食3品（サガリ・黒毛和牛ロース・黒毛和牛ヒレ）だけに付けている。写真を足すときは `tools/README.md` の「写真を足す・差し替える」を参照。

## デザイン

お店自身の意匠から組んでいる。紙のメニュー表（白い紙、紅の見出し、料理ブロック左の紅い縦罫と名前下の横罫、価格までのリーダー罫、● 付きの注記）と、ロゴ（麻布のような地・墨の筆文字・朱の落款）。

- 色（`style.css` の `:root`）：墨 `#231815`（本文・下の固定バー・店員画面の見出し）／紅 `#9c1c1c`（見出し・ボタン・選択中）／麻 `#d6cab9`（暖簾・ヘッダーの布地。織り目はインライン SVG と CSS のグラデーションで再現）／紙 `#ffffff`／金茶 `#8a6d3b`（お持ち帰りの帯・提供タイミング）／鼠 `#6b625b`（補足）
- 書体：外部フォントは使わず、端末の書体だけで組む。欧文は Avenir Next、和文はヒラギノ角ゴ（Android などでは Roboto / Noto Sans CJK）。価格は Avenir Next Condensed。中国語・韓国語は各言語のゴシック（PingFang / Apple SD Gothic Neo / Noto Sans CJK）。店員画面は `lang="ja"` を付けて常に日本の字形で出す
- ボタン：押せるものは一目でボタンと分かる形にする（塗りのボタンは下に濃い縁、ほかは枠と地色）。文字だけのボタンは作らない
- 料理名：`"Unaju — Grilled Eel over Rice…"` は `renderName()` で名前（大）と説明（小）の2段に組む。区切りの「 — 」は画面に出さず読み上げ用に残すので、文字列としては元のまま
- 動き：入口の暖簾（選んだときに約0.8秒）と、カートの数が増えたときに数の四角が判を押すように動くだけ。端末の「視差効果を減らす／動きを減らす」設定（`prefers-reduced-motion`）ではすべて止め、暖簾も即切り替え
- `assets/logo-ink.webp`：`logo.png` の暗い画素（墨）と赤い画素（落款）だけを残して透過にし、「川」と「淀」の間の余白が画像の横中央に来るように切り出したもの（暖簾の左右の切れ目に合わせるため）。ロゴを差し替えたときは作り直す

## デプロイ

GitHub Pages が `main` ブランチのルートから直接配信している（ビルド・GitHub Actions なし）。`main` に push すれば数分で反映される。
